# Design System — СтройМат (фронтенд)

Единый стиль для всех страниц, виджетов и компонентов. Источник истины для
агента — скилл `.opencode/skills/design-system/SKILL.md`; этот документ —
человекочитаемая версия для команды.

## Стек

React 19 + **MUI v7** (`@mui/material`, `@mui/icons-material`) + Emotion (`sx`).
Tailwind удалён — стилизуем только через MUI.

## Анализ текущего дизайна

### Плюсы
1. **MUI как фундамент** — доступный, темизируемый, проверенный UI-кит.
2. **Тёмная/светлая тема** через `ThemeContext`.
3. **Консистентный каркас страницы** — заголовок `h4` + строка действий, далее таблица/диалог.
4. **Переиспользуемый `ActionModal`** для подтверждений удаления.
5. **`sx`** даёт локальные, читаемые стили.

### Минусы
1. **Закодированные цвета** в компонентах (`#1976d2`, `#2e7d32`, `#ed6c02`, `#888`, `#ddd`) вместо токенов темы.
2. **Тема минимальна** — только primary/secondary; нет success/warning/error/info, шкалы отступов и типографики.
3. **Разнобой отступов** — `mb: 2`/`mb: 3`, `p: 2`/`p: 4`, сырые `1.5`, `2rem`.
4. **Два стиля таблиц** — MUI `Table` (большинство) и сырой `<table>` (дашборд).
5. **Разнобой пустых состояний** — `#888` vs `text.secondary`.
6. Нет кастомной типографики (default MUI).

## Цвета

Не хардкодить hex — брать из темы.

| Токен      | Light     | Dark      | Назначение |
|------------|-----------|-----------|------------|
| primary    | `#1976d2` | `#90caf9` | бренд, действия, ссылки |
| secondary  | `#dc004e` | `#f48fb1` | акцент |
| success    | `#2e7d32` | `#66bb6a` | завершено / позитив |
| warning    | `#ed6c02` | `#ffa726` | ожидание / в работе |
| error      | `#d32f2f` | `#f44336` | ошибка / отменено |
| info       | `#0288d1` | `#29b6f6` | информация |

## Типографика

- Шрифт: Roboto (MUI default).
- Заголовок страницы: `h4` + `sx={{ mb: 3 }}` (вес 700 задаёт тема).
- Заголовок секции: `h5`/`h6` + `sx={{ mb: 2 }}`.
- Основной текст: `body1`; вторичный: `body2` + `text.secondary`.

## Отступы (сетка 8px)

База 8px. `mb: 2` = 16px, `mb: 3` = 24px.

- Страница: `py: 3`.
- Шапка страницы: `mb: 3`.
- Фильтры: `gap: 2`, `mb: 3`.
- Поля формы: `gap: 2`.
- Карточка: `p: 3` (список) / `p: 4` (детали/форма).

## Каркас страницы

- `AppBar` sticky, `color="default"`, `elevation={2}`: бренд + `Tabs` + действия.
- Контент: `Container maxWidth="xl"` + `py: 3`.
- Шапка: flex `justifyContent: space-between`, `alignItems: center`, `mb: 3`.

## Паттерны компонентов

- **Кнопки**: основное `contained`, вторичное `outlined`, деструктив `color="error"`.
- **Таблицы**: `TableContainer component={Paper} elevation={1}` + MUI `Table size="small"` (не сырой `<table>`).
- **Пустое состояние**: `<TableCell colSpan={n} align="center" sx={{ py: 4, color: 'text.secondary' }}>`.
- **Формы**: `Dialog maxWidth="sm" fullWidth` + `DialogContent` flex-column `gap: 2` + `DialogActions` (Отмена / Сохранить).
- **Детали**: `Card elevation={2}` + `CardContent p: 4`.
- **Статусы**: `Chip` с семантическим цветом + русская подпись.
- **Удаление**: `ActionModal`.
- **Уведомления**: `react-toastify` bottom-right.

## Do / Don't

✅ `sx` + токены темы; сетка 8px; MUI `Table`; семантические цвета.
❌ хардкод hex; микс Tailwind; сырой `<table>`; разнобой отступов.
