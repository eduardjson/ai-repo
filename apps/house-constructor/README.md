# Конструктор дома

Интерактивное 3D-приложение для моделирования малоэтажного дома — от фундамента до
стропильной системы и покрытия кровли. Построено по архитектуре **Feature-Sliced Design (FSD)**.

## Module Federation (интеграция с хостом)

Это приложение — **remote** в составе системы СтройМат. Оно самодостаточно и
подключается к хосту через Module Federation (`@module-federation/vite`):

- экспортирует функцию `mount(container)` из `src/remote.tsx` (expose `./mount`);
- **не шарит с хостом** React и прочие зависимости — бандлит собственный стек
  (React 19.3, HeroUI, Tailwind, R3F, Redux Toolkit);
- глобальные стили, которые не должны «протекать» в хост, вынесены в
  `src/app/styles/base.css` и подключаются только в standalone-режиме (`main.tsx`).

Standalone-режим (`npm run dev`) служит для разработки интерфейса без хоста.
В продакшене приложение собирается как remote и грузится хостом в рантайме.

## Технологии

- **React 19** + **Vite 8** + **TypeScript**
- **Three.js** через **@react-three/fiber** и **@react-three/drei**
- **Redux Toolkit** + **React Redux** — управление состоянием
- **HeroUI** — UI-компоненты
- **Tailwind CSS** — стили

## Возможности

- Слои конструкции: **Фундамент**, **Перекрытие пола**, **Стены 1-го этажа**, **Перекрытие**,
  **Стропильная система**, **Покрытие кровли**.
- Свитчи видимости слоёв + глобальный режим «Скрытые слои — 30%» (полупрозрачные скрытые слои).
- Работа с каждым слоем отдельно: своя координатная сетка на рабочей отметке слоя.
- Создание элементов **мышью** и **числами**:
  - контур здания — протягиванием прямоугольника по земле (инструмент «Контур»);
  - окна/двери — кликом по стене (инструменты «Окно»/«Дверь»), с дальнейшей точной правкой в полях;
  - все параметры слоёв и здания — в панели «Параметры».
- Выбор проёма в 3D, редактирование и удаление.
- Виды камеры: 3D / сверху / фасад / бок, сброс камеры.

## Архитектура (FSD)

```
src/
├── app/            # Инициализация: корневой App, Redux-стор, типизированные хуки, глобальные стили
├── pages/          # Страница «Конструктор» (компоновка виджетов)
├── widgets/        # Крупные блоки UI: панель слоёв, свойства, тулбар, 3D-вьюпорт, сцена
├── features/       # Пользовательские сценарии: инструменты, размещение проёмов,
│                   #   рисование контура, полупрозрачные слои, виды камеры
├── entities/       # Доменные сущности и чистая геометрия:
│   ├── building/   #   габариты и положение здания
│   ├── layer/      #   слои, их параметры, отметки, генераторы геометрии
│   └── opening/    #   проёмы (окна/двери) и геометрия стен
└── shared/         # Переиспользуемые утилиты (математика, форматирование, id)
```

Каждый модуль экспортирует свой публичный API через `index.ts`.
Слои зависят строго «сверху вниз»: `app → pages → widgets → features → entities → shared`.

### Как устроено состояние (Redux Toolkit)

Состояние хранится в одном Redux-сторе (`app/store.ts`). Каждая сущность и фича
экспортирует свой slice (`model/slice.ts`) с actions и reducer'ом, которые собираются
в `configureStore`. Для доступа из компонентов используйте типизированные хуки
`useAppSelector` / `useAppDispatch` из `app/hooks.ts` вместо обычных `useSelector`/`useDispatch`.

### Как устроена геометрия

Геометрия — это **чистые функции** (в `entities/**/lib`), которые из параметров возвращают
массив боксов/треугольников (`BoxSpec` / `TriangleSpec`). Отрисовка — это тонкие компоненты
в `widgets/scene/ui/layers`, которые не знают о правилах моделирования, а только рисуют
спецификацию. Это позволяет легко менять и тестировать геометрию отдельно от рендера.

### Как добавить новый параметр слоя

1. В `entities/layer/model/definitions.ts` добавьте запись в `paramDefs` нужного слоя
   и значение по умолчанию в `defaultParams`.
2. В соответствующем генераторе (`entities/layer/lib/generators/*.ts`) используйте параметр.
3. Всё остальное (панель свойств, стор) подхватится автоматически.

### Как добавить новый слой

1. Добавьте тип в `LAYER_TYPES` (`entities/layer/model/types.ts`).
2. Опишите слой в `LAYER_DEFINITIONS`.
3. Создайте генератор и компонент отрисовки, подключите его в `HouseScene`.

## Ключевые соглашения

- Все размеры — в **метрах** (1 единица Three.js = 1 м).
- Слои по умолчанию скрыты; отображается только координатная сетка активного слоя.
- Открытия «вырезаются» из стен разбиением стены на перемычки/простенки/подоконные участки.
